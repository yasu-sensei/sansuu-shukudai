# 学校用モードの構成

## 実装済みの責務

| 場所 | 内容 |
| --- | --- |
| `src/domain/` | 元の出題セット・完了・ポイント・連続ボーナス、モード定義 |
| `src/server/classroom.mjs` | 初回登録、教師権限、名簿・宿題・目安、再採点、取り組み状況・支援目安、イベント投影 |
| `src/gas/Code.gs` | ActiveUserメール、Script Properties、暗証番号検証・試行制限、シート保存、ScriptLock、doGet、API |
| `src/client/classroom-api.mjs` | google.script.run、同じ操作IDでの再送、解答バッチの保存 |
| `src/client/game.mjs` | 既存児童画面、初回確認・アカウント照合、配信・記録連携、端末内試作モード |
| `src/client/teacher.*` | 名簿・暗証番号・配信・取り組み状況・支援目安の画面 |
| `scripts/build-gas.mjs` | 児童・教師HTMLとサーバーのGAS用バンドルを生成 |

## 名簿と認証

児童メールの事前登録は不要です。学校ドメインのGoogleアカウントから、学級・番号の確認済み操作を受けて1人分を登録します。内部studentIdとメールはサーバーで決めます。別メールの同じ番号は上書きできず、登録後の自己変更もできません。

初回の番号の正しさは事前名簿なしでは証明できません。学校メール・学級・番号・変更できるのは先生のみであることを表示し、チェックして確定します。先生は名簿で確認・訂正できます。訂正にはGoogleアカウントの教師権限と暗証番号の両方が必要です。名前の自動取得は行いません。

教師の権限はスクリプトプロパティの許可リストで決定し、児童の操作から教師を追加できません。学校外・メール取得不可は拒否し、デプロイ所有者のメールで代用しません。

## 保存の正本

`ClassroomEvents` の列は次のとおりです。

```text
event_id | server_time | event_type | actor | request_id | event_json
```

イベントには操作の種類、学校メール、操作ID、公開可能な入力の指紋、変更内容、再送用の結果を保存します。暗証番号の原文は入力の指紋にも含めません。各コマンドをScriptLock内で検証し、1行で確定します。複数シートで残高と記録を別々に書き換える方式は採用していません。

投影するデータは、児童、学級・日付別宿題、学習セッションと回答、児童・宿題別の完了、ポイント残高と付与済みボーナス、モード別の目安、操作IDごとの確定結果です。UUIDを識別子とし、年度ごとに保存先を分けます。

同じ操作ID・同じ入力は同じ確定結果を返します。異なる入力での再利用は拒否します。返答を失った完了操作でも、既に確定したイベントから結果を復元します。完了結果に含まれる最新カレンダーは保存ログから再構築し、イベント内に全履歴を重複保存しません。

## 学習とポイント

開始時にサーバーがモード・乱数シードを確定し、児童画面と同じ出題生成器で問題を作ります。回答には連番・問題番号・入力値・経過ミリ秒を付け、サーバーで順番と正誤を再計算します。1回目の誤答は同問、2回目で次問、正答650ms／誤答900msの待ち時間も検証します。

最初の120秒未満の正解数×倍率＋10、120秒以上かつ10問以上正解、元の連続宿題ボーナスを維持します。自由練習には学校用セッションも報酬も作りません。完了は児童＋宿題で一度だけです。開始済み宿題のモード変更は拒否します。

途中は5回答／15秒ごとに保存し、先生画面へ反映します。5分間通信がないと中断として扱い、新しい宿題を開始すると以前の実行中セッションを中断にします。実時計・端末時計の不整合は検証しますが、解答者が人間であることや端末時刻の完全な正当性は証明できません。

## 支援の目安

今年度・同じ児童・同じモードの完了記録から、完了時刻順で直近3件を使用します。目安未設定と記録不足を分け、3件中2件以上が目安未満なら「ようすを確認」とします。正解数と正答率を先生だけに表示します。未着手・中断はこの評価に使わず、児童側へ順位や評価を返しません。

## 対象外・残る検証

ガチャ・図鑑、端末引継ぎ専用機能、既存localStorageの自動移行、年度切替の自動移行、直接のシート編集・取消・ポイント訂正のUIは対象外です。過去日への宿題追加による連続ボーナスの再評価は元仕様のままです。

学校Workspaceでのメール取得可否とシート権限、デプロイ、実機と同時利用、履歴増加時の索引・集計保存は別途確認が必要です。詳細は [gas-setup.md](gas-setup.md) を参照してください。

開発に必要な元ファイルと画像をGitHubで保管し、後の統合時に参照できるようにします。このフォルダは資料用です。宿題アプリの入口やGAS配信物には組み込んでいません。

添付された `homework_math_calendar_keypad_practice_v10-1.html` は、既存の `homework_math_calendar_keypad_practice_v10.html` とバイト単位で同一でした。同じ内容を二重管理せず、既存のファイルを保管先とします。

ガチャHTMLは添付された元ファイルを加工せずに保管しています。JPEG画像は32種類すべてHTML内のBase64データに含まれます。通常30種類・シークレット2種類です。現時点で別の画像ダウンロードや画像ファイルの追加は不要です。将来の開発で画像を分離しても、提供されたこの原本は変更せず保持します。

## 試作ガチャと確定仕様の対応

- 1回100ポイント、通常グループ90%・シークレットグループ10%。グループ内は残存カードから均等抽選。
- 初回獲得でノーマル、次にゴールド、3回目で最終段階へ進化。
- 最終進化したカードは抽選対象外。一方のグループが完成すると、残るグループから排出。
- 全32種類完成時はガチャ停止。獲得済みだけを図鑑表示。
- 試作版の最終段階名は「スペシャル🌈」。統合時には確定仕様の「レインボー」と表記を合わせる。
- 初期500ポイント、試用の「＋500pt」、デモリセットがある。これらは本番向けのポイント機能ではない。
- 現在は `daratto_gacha_demo_v1` というlocalStorageキーにポイントと進化段階を保存する。宿題アプリとは未連携で、抽選履歴・児童別保存・サーバー側確定・二重実行防止は未実装。

今後の統合では演出・画像を活用し、残高・抽選・進化・履歴をGAS側で管理します。今回の保管作業ではゲームの統合や原本の修正を行いません。

## GitHubで保管するもの

- アプリのソース、提供された元HTML、提供素材、仕様・設計・手順書、テスト、依存関係のロックファイル。
- 今後提供されるカード画像なども、用途・出典とともにリポジトリへ追加する。
- `node_modules/`、再生成できるビルド出力、テストの一時出力は追加しない。ソースと実行手順から再作成する。
- 児童名簿・学習記録・Google認証情報・パスワードはリポジトリへ保存しない。

第2段階のコード整理・GAS配信準備は別PRで管理されています。この保管用PRはmainを基点にしており、第2段階の統合とは独立しています。
